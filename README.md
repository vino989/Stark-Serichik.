# Stark Serichik v0.7 — проект для двух друзей

Личный Android-прототип для тебя и твоего друга: броня, реактор, коллекция модулей, мини-миссии и идея совместного «серийчика».

## Что есть в v0.7

- Обновлённый экран в стиле технологичной лаборатории и собственная векторная иллюстрация брони.
- Главный экран с реактором, SC, XP, серией и коллекцией модулей.
- Арсенал Mark I–V, аксессуары, экипировка и улучшения.
- Мини-миссии с фиксированными ежедневными наградами.
- Кейс с заранее известным содержимым.
- Локальные промокоды и сохранение прогресса на устройстве.
- Демонстрационные экраны чата и поиска.

## Важно для тебя и друга

Сейчас это **локальная версия для тестирования**, а не полноценное сетевое приложение. Данные хранятся на каждом телефоне отдельно. Совместное удержание кнопок на двух устройствах, общая серия, общий профиль, синхронизация прогресса и настоящий чат пока не подключены. Чтобы вы могли играть вместе с двух телефонов, потребуется серверная часть и авторизация.

Не вводите реальные пароли, личные или платёжные данные в демонстрационные экраны.

## Получить APK

После загрузки исходников в GitHub откройте вкладку **Actions**, выберите **Android APK** и запустите workflow через **Run workflow**. После успешной сборки откройте запуск и скачайте artifact `stark-serichik-debug-apk`; внутри будет `app-debug.apk`.

Это debug-APK для установки и тестирования, не релиз Google Play.
